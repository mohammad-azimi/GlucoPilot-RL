PHASE 3 — HELD-OUT BASELINE GENERALIZATION

Copy this project's files over your existing GlucoPilot-RL folder without deleting .venv.
No new Python packages are required.

Run:
  python scripts\evaluate_baseline_generalization.py

This freezes action=0.0450 selected on adult#001/standard-day/seed=42 and tests it
on held-out virtual adults and meal scenarios. Do not use results from held-out cases
to retune the baseline; they become the future comparison suite for the RL policy.
